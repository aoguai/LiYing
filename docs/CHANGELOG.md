# 更新日志

[English](./CHANGELOG-EN.md)

**注意该版本对 CIL 参数进行了更改，为了避免问题请你仔细阅读最新 CIL 帮助文档**

- **2026/10/03 更新**
  - 新增 按宽高比例裁剪，支持选择是否生成排版照 (#18)
  - 新增 人脸高度与头顶边距控制，CLI、BAT 和 WebUI 均支持按人脸位置调整构图 (#22)
  - 新增 基于 ONNX 的人像磨皮与美白，支持 CLI、BAT 和 WebUI，并可分别调节磨皮与美白强度
  - 新增 可选的 RetinaFace 人脸检测，用于照片排版流程
  - 修复 YOLOv8 对带透明通道的 RGBA PNG 图片的预处理问题
  - 修复 图像方向处理与旋转裁剪问题，统一 EXIF 读取和检测图像来源，并修正肩部关键点映射及裁剪坐标计算 (#21)
  - 修复 YuNet 人脸框坐标格式转换，改善人像构图裁剪
  - 修复 中文 BAT 启动脚本的 GBK 编码乱码
  - 补充 Docker 的 `libgl1` 运行依赖 (#20)
